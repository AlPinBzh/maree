# Marée

Suivi de cycle menstruel (règles, température, glaire, forme), selon la méthode symptothermique.

- Une seule page : `index.html`. Pas de compte, pas de serveur.
- Les données restent sur le téléphone (stockage du navigateur). Sauvegarde : Mon cycle → Copier mes données.
- Mise en ligne : GitHub Pages, branche `main`, dossier racine.
- Sur iPhone : ouvrir le lien dans Safari → Partager → Sur l'écran d'accueil. Toujours ouvrir l'app depuis l'icône.
